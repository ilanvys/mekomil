# Unserved skills

This is a holding list for skills discovered outside mekomIL's supported fetch path. An entry here is
not part of the mekomIL catalog, is not routed to `get_skill`, and is not a commitment to support it.

Keep only enough information to create a useful community issue later:

| Skill | Official location | Why mekomIL cannot fetch it | Separate setup |
|---|---|---|---|

After the public repository is ready, suitable entries can become individual GitHub issues open to
community contributions. Until then, keep them here rather than expanding the release scope.
